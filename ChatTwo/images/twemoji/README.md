# Twemoji + Emojibase

To update the emoji assets and definitions, you must run `Update-Twemoji.ps1`.

This directory contains a copy of Twitter's Twemoji at the following commit:

https://github.com/twitter/twemoji/commit/bad3bceeafc901ace42a3dfe0421db6388daafb9
